Actividad 1

Crea una aplicación web con Spring Boot y Tomcat sobre el tema que quieras. Puede ser una aplicación sencilla generada con IA, ya que lo importante será el despliegue.

Construye y sube una imagen de Docker de tu aplicación. Luego, despliega la aplicación en Render, y asígnale un dominio personalizado.

La entrega debe ser un documento en el que expliques paso a paso y con capturas de pantalla (las que consideres oportunas) todo el proceso. En particular, el documento debe incluir:
El repositorio de la aplicación con Spring Boot.
Los pasos para construir y subir la imagen de Docker.
El enlace de la imagen de Docker en Docker Hub.
Los pasos para desplegar la aplicación en Render.
Los pasos para configurar el dominio personalizado.
El enlace de la aplicación.
